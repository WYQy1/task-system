# 分布式任务系统（Distributed Task System）

**Version: v1.0**

基于 Go、Gin 和 MySQL 开发的任务管理后端项目，主要实现员工信息管理与个人任务管理，围绕 RESTful API、数据库操作、自动化测试和基础工程化实践展开。

当前版本已完成核心 CRUD 接口、自动化测试及基础代码重构，后续将逐步完善系统架构与工程化能力。

## 一、技术栈

| 技术 | 用途 |
|---|---|
| Go 1.25 | 后端开发语言 |
| Gin | HTTP Web 框架 |
| MySQL | 关系型数据库 |
| database/sql | 数据库操作 |
| go-sql-driver/mysql | MySQL 驱动 |
| godotenv | 环境变量配置管理 |
| Go testing | 自动化测试 |

## 二、已实现功能

### 1. 员工管理

- 创建员工
- 查询员工列表
- 根据 ID 查询员工
- 更新员工信息
- 删除员工
- 删除员工时同步处理其关联任务

### 2. 任务管理

- 创建员工任务
- 查询员工任务列表
- 查询单条任务
- 更新任务信息
- 删除任务
- 任务与员工建立关联关系
- 任务列表按照 ID 升序排列

### 3. 参数校验与错误处理

- 员工 ID、任务 ID 格式校验
- 必填参数校验
- 任务标题长度限制（最大 100 字符）
- 任务标题空值及纯空格校验
- 任务状态合法性校验
- 数据库查询与操作错误处理
- HTTP 状态码处理

任务状态包括：

- `pending`：待处理
- `in_progress`：进行中
- `completed`：已完成

## 四、数据库设计

目前使用 MySQL，主要包含两张数据表：

### users

员工信息表，保存员工基本信息。

主要字段：

- `id`：员工 ID
- `name`：员工姓名
- `age`：员工年龄
- `gender`：员工性别

### tasks

任务信息表，保存员工任务。

主要字段：

- `id`：任务 ID
- `user_id`：所属员工 ID
- `title`：任务标题
- `description`：任务描述
- `status`：任务状态
- `created_at`：任务创建时间

通过 `tasks.user_id` 与 `users.id` 建立外键关联，实现员工与任务之间的一对多关系。

## 五、自动化测试

目前已经建立基础自动化测试体系。

测试范围包括：

- 员工 CRUD 接口
- 任务创建、查询、更新和删除
- 非法 ID 参数
- 员工不存在
- 任务不存在
- 任务归属隔离
- 任务标题参数校验
- 任务状态合法性校验
- 数据库操作结果验证

测试辅助函数统一放在 `test_helpers_test.go`，减少重复测试代码。

执行测试：

```bash
go test -count=1 ./...
```

执行静态检查：

```bash
go vet ./...
```
